# Button

Button 컴포넌트는 Radix UI의 Slot을 활용하여 구현된 다용도 버튼 컴포넌트입니다.

## 특징

- Slot 패턴을 통한 다양한 엘리먼트로의 확장성
- 접근성을 고려한 키보드 포커스 스타일
- 다양한 상태와 크기 지원

## 변형 (Variants)

버튼은 다음과 같은 스타일 변형을 지원합니다:

<div>
  <Button>ㅎㅇ</Button>
  <Button variant="secondary">ㅎㅇ</Button>
  <Button variant="ghost">ㅎㅇ</Button>
  <Button variant="destructive">ㅎㅇ</Button>
</div>

```
<Button variant="primary">ㅎㅇ</Button>
<Button variant="secondary">ㅎㅇ</Button>
<Button variant="ghost">ㅎㅇ</Button>
<Button variant="destructive">ㅎㅇ</Button>
```
