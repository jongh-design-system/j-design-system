## Introduction

This library adapts shadcn's powerful CLI features to PandaCSS syntax. It's currently being developed as part of my learning process

## Initialize

<CommandCodeBlock
  command={{
    npm: "npx @jongh/cli init",
    pnpm: "pnpm dlx @jongh/cli init",
    yarn: "yarn @jongh/cli init",
  }}
/>

## Add

<CommandCodeBlock
  command={{
    npm: "npx @jongh/cli add <components>",

  }}
/>
